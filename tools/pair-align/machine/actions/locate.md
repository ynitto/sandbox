## [locate: ペアのリポジトリで反映先を探す]

`.pair-align/work/changes.md` と、前のステートで挙げた揃えるべき点を材料にします。

**揃えるべき点:** {{assessment}}

1. 相手の側で使われていそうな語（機能名・画面や API の名前・用語・見出し）を 3〜8 個選び、次のコマンドで探してください。
   `changes.md` の「検索語の候補」は自動で足されるので、それ以外の語を選びます。

   ```bash
   python3 .statemachine/pair_align/pair_align.py locate --term "語1" --term "語2"
   ```

   相手のリポジトリに graphify の知識グラフがあれば、コマンドがそれを使って関係するノードをたどります
   （グラフが古いと思うときは `--refresh` を付ける）。
2. `.pair-align/work/candidates.md` を読み、候補のファイルのうち本当に関係する箇所を、相手のリポジトリで開いて確かめてください。
   読むのは候補に挙がった箇所の前後だけにし、相手のリポジトリ全体を読まないでください。
3. 相手のリポジトリのファイルは**変更しないでください**。

**出力形式:** 第 1 行に `FOUND`（直すべき既存の箇所がある）か `NEW`（該当箇所が無く、新しく書く必要がある）の一語。
第 2 行以降に `- 相手のリポジトリからの相対パス（見出しや関数名） — 何を直すか` の形で箇所を列挙してください。

この指示に従ってタスクを実行してください。
完了後、指定された形式で出力のみを返してください。次のステップは別途指示されます。
