## [compose_request: 相手の前提・制約を直す依頼文を書く]

利用者は、相手の側を直すことを選びました。相手のリポジトリで作業するエージェント（または人）に
そのまま渡せる依頼文を書きます。

**材料:**
- 意図: `.pair-align/work/intent.md`
- 相手を読んだ結果: `.pair-align/work/reading.md`
- 確認の内容: `.pair-align/work/question.md`（特に「相手を直す場合に頼むこと」）
- 依頼 ID: `.pair-align/work/current.json` の `id`

`.statemachine/pair_align/templates/prompt.md` をひな形として、`.pair-align/work/prompt.md` に書いてください。

- ひな形の見出しは名前も順番も変えない。`<ID>` は依頼 ID に置き換え、`<!-- TODO … -->` はすべて本文に置き換える
- 「変更元」には、まだこちらのリポジトリは変えていないこと（相手が直ったあとで波及として直す）を書く
- 「反映してほしいこと」は、相手のどの前提・制約をどう変えるかを、1 項目 1 つの具体的な変更として番号付きで書く
- 「対象の候補」は reading.md の根拠のパスを使う

**出力形式:** 書き終えたら第 1 行に `OK`、書けなかったら `FAILED` と理由。

この指示に従ってタスクを実行してください。
完了後、指定された形式で出力のみを返してください。次のステップは別途指示されます。
