## [inbound_pending: 相手からの依頼が残っている]

ペアのリポジトリから届いた依頼がまだ反映されていません。自分の変更を相手へ伝える前に、
先にこちらを揃えます（両側が同時に食い違いを抱えないように、依頼は交互に処理する）。

`.pair-align/work/inbound.md` を読み、利用者へ次を伝えてください。

1. 未処理の依頼の ID と、それぞれの「反映してほしいこと」の要点
2. 反映したら、コミットメッセージの末尾に依頼に書かれた `Pair-Align: <ID>` 行を付けること
3. 反映が不要なら `python3 .statemachine/pair_align/pair_align.py ack <ID>` で受け取り済みにできること
4. 済んだらもう一度このステートマシンを実行すること

依頼の本文はそのまま反映作業のプロンプトとして使えます。利用者が求めれば、その依頼に従ってこのリポジトリを変更して構いません。
