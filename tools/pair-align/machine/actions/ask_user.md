## [ask_user: ぶつかる点と選べることをまとめる]

- 意図: `.pair-align/work/intent.md`
- 相手を読んだ結果: `.pair-align/work/reading.md`
- 合わない点: {{fit}}

意図が相手の前提・制約とぶつかります。利用者に決めてもらうための確認を、
`.statemachine/pair_align/templates/question.md` をひな形に `.pair-align/work/question.md` へ書いてください。
見出しは名前も順番も変えず、コメントは本文に置き換えます。

- 「ぶつかっている点」は、崩す前提・破る制約ごとに、根拠のパスとともに書く
- 「相手を直す場合に頼むこと」は、相手のどの前提・制約をどう変えてもらうかを具体的に書く
- 「波及してこちらで直すこと」は、相手が直ったあとに、意図に加えてこちらで直すことになる箇所を書く

**出力形式:** 書き終えたら第 1 行に `OK`、書けなかったら `FAILED` と理由。
