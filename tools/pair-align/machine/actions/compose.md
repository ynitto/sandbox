## [compose: ペアへの依頼文を書く]

ペアのリポジトリで作業するエージェント（または人）にそのまま渡せる依頼文を書きます。

**材料:**
- 変更の詳細: `.pair-align/work/changes.md`（依頼 ID もここにある）
- 揃えるべき点: {{assessment}}
- 反映先: {{locations}}

`.statemachine/pair_align/templates/prompt.md` をひな形として、`.pair-align/work/prompt.md` に書いてください。

- ひな形の見出しは名前も順番も変えない。`<ID>` は `changes.md` の依頼 ID に置き換える
- `<!-- TODO … -->` のコメントはすべて本文に置き換え、残さない
- 「反映してほしいこと」は、相手の側の言葉で、1 項目 1 つの具体的な変更として番号付きで書く。
  差分をそのまま貼らず、何がどう変わったので何をどう直すのかを書く
- 「対象の候補」には反映先のパスを書く。新しく書く必要があるときは、置く場所の案を書く
- 判断が付かない点は勝手に決めず、「確認してほしいこと」として書く

**出力形式:** 書き終えたら第 1 行に `OK`、書けなかったら `FAILED` と理由。

この指示に従ってタスクを実行してください。
完了後、指定された形式で出力のみを返してください。次のステップは別途指示されます。
