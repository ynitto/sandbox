# csv-peek

CSV の行数・列数、列名、列ごとの型と値の分布、先頭のサンプル行を表示する CLI です。Python 3 の標準ライブラリだけで動作します。

## 使い方

リポジトリのルートから実行します。

```sh
python3 tools/csv-peek/csv_peek.py records.csv
python3 tools/csv-peek/csv_peek.py records.csv --limit 1000 --sample 3 --json
python3 tools/csv-peek/csv_peek.py records.tsv --delimiter tab --no-header
python3 tools/csv-peek/csv_peek.py - --encoding shift_jis < records-sjis.csv
```

| オプション | 動作 |
| --- | --- |
| `--delimiter 文字` | 区切り文字を指定します。タブは `tab` または `'\t'` でも指定できます。 |
| `--no-header` | 先頭行をデータに含め、列名を `col1`、`col2` のように付けます。 |
| `--sample N` | 先頭のサンプルを最大 N 行表示します。既定は 5 行です。 |
| `--limit N` | 先頭 N データ行までを集計します。表示される行数や列統計はその範囲のもので、ファイル全体の行数は数えません。 |
| `--json` | 標準出力に JSON を表示します。`row_count`、`column_count`、`headers`、`columns`、`sample_rows` などを含みます。範囲指定時は `limit` に指定値が入ります。 |
| `--encoding 名前` | Python が認識する文字コード名で自動推定を上書きします。 |

列数は読み取った範囲の最大幅です。ヘッダー（`--no-header` の場合は先頭データ行）と幅が違うデータ行の件数を標準エラーに警告し、JSON では `uneven_row_count` にも記録します。不足するセルは空欄として扱い、ヘッダーより右に追加された列には位置に応じて `colN` を付けます。

## 推定と集計の方針

- **文字コード**は UTF-8 BOM を優先し、それ以外は読み取った範囲を UTF-8 として解釈し、デコードできなければ Shift_JIS で先頭から読み直します。ASCII だけの入力や両方でデコードできる入力は UTF-8 と判定します。`--limit` の範囲に日本語などが含まれない場合も推定が外れることがあります。
- **区切り文字**は最初の物理行に対して `csv.Sniffer` でカンマ・タブ・セミコロン・パイプから推定します。推定できなければ各候補で解析した列数が最も多いものを使い、同数の場合はこの順に選びます。複数行にわたる引用フィールドや複数の候補を含む行では推定が外れる場合があります。
- **型**は空欄を除いた値の過半数で決めます。整数と小数（指数表記を含む有限の値）は同じ数値グループで数え、そのグループに小数があれば `decimal`、整数だけなら `integer` です。最小・最大は数値として解釈できた値から求めます。ISO 形式の日付・日時・時刻は `datetime`、大文字小文字を問わない `true/false/yes/no` は `boolean` です。`0/1` は整数として扱い、その他は `string` です。過半数の型がなければ `mixed`、すべて空欄なら `string` です。数字だけの識別子などは意図と異なる型に推定されることがあります。
- **空欄とユニーク数**の集計では値の前後の空白を除去します。空文字列と空白だけのセルを空欄とし、ユニーク数には空欄を含めません。大文字小文字や数値の表記の違いは別の値として数えます。

## 終了コード

| コード | 意味 |
| --- | --- |
| 0 | 正常終了。列数にばらつきがある場合も含みます。 |
| 2 | ファイルを開けない、デコードできない、CSV を解析できない、引数が無効などの入力エラー。理由は標準エラーに表示します。 |
