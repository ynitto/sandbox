# timestamp-converter

Unix epoch と ISO 8601 / RFC 3339 の日時を相互変換する CLI です。Python 3.9 以降の標準ライブラリで動作します。

## 使い方

リポジトリのルートで実行します。

```sh
python3 tools/timestamp-converter/timestamp_converter.py --tz Asia/Tokyo 1700000000 1700000000000
python3 tools/timestamp-converter/timestamp_converter.py --tz Asia/Tokyo '2024-01-01 09:00:00'
printf '%s\n' '2024-01-01T00:00:00Z' '2024-01-02' | python3 tools/timestamp-converter/timestamp_converter.py --tz UTC --json
python3 tools/timestamp-converter/timestamp_converter.py --now --tz UTC
```

位置引数がない場合は、パイプやリダイレクトから入力を1行ずつ読み、空行をスキップします。各変換結果には epoch 秒、epoch ミリ秒、UTC の日時、指定タイムゾーンまたはローカルの日時が含まれます。

## オプション

| オプション | 説明 |
| --- | --- |
| `--unit s\|ms\|auto` | 数値入力の単位。既定は `auto`。 |
| `--tz NAME` | IANA タイムゾーン名。省略時はシステムのローカルタイムゾーン。 |
| `--now` | 現在時刻の変換結果を先頭に表示する。 |
| `--json` | 結果を JSON で出力する。 |
| `-h`, `--help` | ヘルプを表示する。 |

## 変換規則

- 符号付きの整数・小数は epoch として解釈します。既定の自動判定では、絶対値が `1000000000000` 以上ならミリ秒、それ未満なら秒です。
- 日時は `Z`、`±hh:mm` のオフセット、日付のみの形式、時刻との空白区切りに対応します。日付のみの場合は午前0時になります。オフセットがない場合は、指定タイムゾーンまたはシステムのローカル時刻として解釈します。
- JSON オブジェクトには `input`、`epoch_s`、`epoch_ms`、`utc`、`local`、`timezone` が含まれます。 `--now` の `input` は `"now"` です。入力が複数ある場合は成功した結果を配列で返します。入力が1件で成功した場合はオブジェクト、成功が0件の場合は空配列を返します。

## 既知の制限

- Python の `datetime` が表現できる年の範囲は 1〜9999 年です。自動判定で秒とみなされた値がこの範囲を超える場合があります。ミリ秒として扱うには `--unit ms` を指定してください。
- うるう秒には対応していません。日時の精度はマイクロ秒までです。epoch 入力は最寄りのマイクロ秒に丸め、ちょうど中間なら偶数側に丸めます。
- `--tz` の利用には環境に IANA タイムゾーンデータが必要です。夏時間の切り替えで曖昧な時刻を指定する場合は、入力に明示的なオフセットを付けてください。歴史的なオフセットに秒が含まれる場合、RFC 3339 出力では最寄りの分に丸め、同じ瞬間を表すよう表示時刻を調整します。

## 終了コード

| コード | 意味 |
| --- | --- |
| 0 | すべて変換できた。 |
| 1 | 標準入力で変換に失敗した行がある。失敗理由は標準エラー出力に、成功結果は標準出力に出る。 |
| 2 | 無効な引数やタイムゾーン、位置引数の変換失敗、または入力なし。 |
