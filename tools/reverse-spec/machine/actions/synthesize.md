## 全体の仕様書を書く

検証済みの単位の仕様書:

{{specs}}

1. `specs/overview.md`（全体像）と `specs/cross-cutting.md`（横断の関心事）のひな形を本文に置き換える。
   単位の仕様書を読んでまとめ、単位は `[[SPEC-種類-単位]]` で、ソースは `パス:行` で指す。
2. **単位の仕様書は書き換えない**（検証したあとに変わると、最後の検査が落とす。直す必要に気づいたら
   `FAILED 直したい単位と理由` を渡す）。
3. 単位の仕様書の `UNKNOWN[blocking]` は、overview の「未確定事項」に集める。
4. `specs/index.md` と `specs/source-index.md` はスクリプトが書く。手で直さない。

終えたら `OK`（このあと最後の検査が自動で動く）。
