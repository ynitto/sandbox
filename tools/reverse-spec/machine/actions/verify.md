## 根拠を別の目で確かめる: {{unit}}（{{round}} 回目）

用紙 `{{sheet}}` に、スクリプトが仕様書から選んだ {{claims}} 件の主張と根拠がある。

- **検証用のサブエージェント `rspec-verifier` を使えるなら、「`{{sheet}}` を検証して」と渡し、自分では判定しない。**
  使えないときは自分で判定する。そのときは仕様書（`{{spec}}`）を開かず、根拠の行だけを読む
- 各 `### C番号` の `- 判定: ?` を `OK` か `NG` に置き換え、`NG` なら `- 理由:` にソースでは実際にどうなっているかを書く
- 言い過ぎ（根拠の行からは言えないことまで書いている）・行のずれも `NG`
- 用紙の C 番号・主張・根拠の行は変えない

ソースのフォルダ: `{{source}}`

判定を書き終えたら `OK`（NG があれば、スクリプトが直す段へ回す）。
