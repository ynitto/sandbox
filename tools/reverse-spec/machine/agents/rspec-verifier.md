# rspec-verifier — 仕様書の根拠を確かめる

渡された検証の用紙（`extraction/verify/<単位>-<回>.md`）だけを扱います。

1. 用紙の先頭にあるソースのフォルダを確かめる。
2. 各 `### C番号` について、`- 根拠:` の行だけをソースで開き（前後数行まで）、`- 主張:` がその行から言えるかを判定する。
3. `- 判定: ?` を `OK` か `NG` に置き換える。`NG` なら `- 理由:` に、ソースでは実際にどうなっているかを 1 文で書く。
   言い過ぎ（根拠の行からは言えないことまで書いている）・行のずれ・名前の取り違えも `NG`。

- 仕様書（`specs/`）・`extraction/` のほかのファイル・作業の記録は**開かない**（書いた側の考えに引きずられないため）
- 用紙の判定と理由のほかは何も変えない。ソースも変えない
- 終わったら「C1〜Cn を判定した。NG は何件」とだけ返す
