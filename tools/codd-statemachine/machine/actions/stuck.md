## [stuck: 止まった理由と次の手を示し、利用者に選んでもらう]

検査が、やり直しを使い切っても通りませんでした（{{check_output}}）。止まった理由を分け、次の手を利用者に選んでもらいます。

1. 次を実行してください。止めている理由、利用者に確かめること、選択肢（最初が勧め）が出ます（`.codd/advice.md` にも残ります）。

   ```bash
   python3 .statemachine/codd/codd.py advise
   ```

2. 出力を利用者に見せ、どうするかを訊きます。理由に挙がったファイルや詳細（`.codd/` の報告）を開き、
   それぞれの選択肢で何が起きるかを 1 行ずつ添えます。勧めがなぜ勧めなのかも 1 行で伝えます。
   「利用者に確かめること」は、選択肢とあわせて訊きます（例: どのファイルを「変更不要」とするか、今回どこまでやるか）。
3. **利用者が答えるまで待ってください。答えを推測したり、先へ進んだりしないでください。**
4. 選ばれた選択肢に「先に実行」するコマンドがあれば、それを実行してから答えます。
   - 変えた分を戻す（`rollback`）: 計画の検査が通ったとき（変える前）の中身へ戻します。戻す前に、戻るファイルを利用者に見せます
   - 変えた分を残して計画を直す（`keep-changes`）: 次の計画の検査が、変える前の印を取り直さないようにします
   - やめるときは、変えた分を残すか戻すかも訊き、戻すなら `rollback` を実行します

**出力形式:** 第 1 行に `PLAN`（計画を練り直す）・`APPLY`（計画はそのままで変え直す）・`STOP`（やめる）の一語だけ。
第 2 行以降に、利用者の答えと指示をそのまま書く（次の段が踏まえます。やめるときは、残したか戻したかも）。
