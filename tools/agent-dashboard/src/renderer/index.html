実行状況

文書を作る

エージェントは別ウィンドウで起動し、書き始める前に読者・目的・範囲・用語・体裁などを徹底的に質問します。答えながら進めてください。

対象・目的・体裁・区分をまとめたファイル。無くても質問で決められます。
出力する形式（複数可）
複数のときは互いに関連づけて作ります（例: Word の本文と、その図の draw.io）。
進め方
入力ファイル
文書フォルダの inputs/ へ写しを置き、エージェントはそれを読みます。

続きを依頼

改訂履歴の決めごとを踏まえて、同じフォルダで作業を続けます。区分ごとに作っている文書は「次の区分へ」のように指示します。

検証する

用語のブレ・整合性・論理性・つながり・人間のわかりやすさ・AI 臭の排除は自動で見ます。専門分野のレビュー結果があれば、ここに貼ると同じ検証で扱います。直すかどうかは一つずつ確認されます。

フィードバック

完成した文書への感想・次回に活かしたい点を書くと、改訂履歴と合わせて文書ルールの案にします。案は確認してから保存します。
