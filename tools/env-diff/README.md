# env-diff

`.env.example` と実際の `.env` など、2 つのファイルを比較します。片方だけにあるキー、値が異なるキー、各ファイル内で重複したキーとその定義行を報告します。Python 3 の標準ライブラリだけで動作します。

## 使い方

リポジトリのルートから実行します。第 1 引数が A、第 2 引数が B です。

```sh
python3 tools/env-diff/env_diff.py .env.example .env
python3 tools/env-diff/env_diff.py --json .env.example .env
python3 tools/env-diff/env_diff.py --show-values .env.example .env
```

既定では、CI ログに秘密情報を残さないよう、値をマスクします。値が異なるキーは「値が違うキー」に表示され、空値は `(空)` と表示されます。値を確認する場合は `--show-values` を指定します。重複キーの欄には、キーと全定義の行番号が表示されます。

`--json` は `only_in_a`、`only_in_b`、`different`、`duplicates_a`、`duplicates_b` を配列として出力します。片方だけにあるキーには `empty` が付き、値が異なるキーでは `a` と `b` の中にそれぞれ `empty` が入ります。`--show-values` を併用すると、これらの値の情報に `value` が追加されます。重複キーの項目には `key` と `lines` が入ります。

## 終了コード

| コード | 意味 |
| --- | --- |
| 0 | 差分なし |
| 1 | 差分あり。重複キーだけの場合も含む |
| 2 | 入力エラー。ファイルの読み込み失敗、書式不正、引数不足などの理由を標準エラーに出力 |

## パース規則

- UTF-8 のファイルを読み込み、空行と、行頭の空白を除いたあとに `#` で始まる行を無視します。
- 行とキー・値の前後の空白を取り除き、`export ` 接頭辞があれば除去します。
- 最初の `=` でキーと値を分け、以降の `=` は値の一部として扱います。
- 値の両端が同じ引用符（`"` または `'`）なら、外側の 1 組を取り除きます。引用符の内側の空白は保持します。`KEY=` や `KEY=""` はキーが存在し、値が空であることを表します。
- 重複キーは 1 始まりの行番号ですべての定義位置を報告し、比較には最後の値を使います。
