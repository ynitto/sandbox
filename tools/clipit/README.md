# ClipIt for Windows

コピーしたテキストと画像を履歴に保存し、画面下部のパネルから貼り直せる Windows 用のクリップボードアプリです。

## セットアップ

Windows 10 または 11 と Python 3.11 以降を用意し、`python` がコマンドとして使える状態にしてください。フォルダ内の `run_clipit.bat` を実行すると、PySide6 と Pillow をインストールして起動します。依存関係をインストール済みの場合は、このフォルダで `python -m clipit` を実行できます。

## 使い方

- **Ctrl+Shift+V** で画面下部のパネルを表示・非表示にします。タスクトレイのメニューからも表示・終了できます。
- **履歴**ではテキストのコピーと画像のコピーを自動で記録します。クリップを選ぶとプレビューが表示され、ダブルクリックまたは一覧にフォーカスした状態で Enter を押すと、パネルを開く前のアプリに貼り付けます。
- **タグ編集**ではタグをカンマ区切りで入力します。タグとキーワードで絞り込み、新しい順・古い順を切り替えられます。ピン留めしたクリップは一覧の先頭に並びます。履歴は最大 200 件です。上限に達するとピン留めしていない最古のクリップが削除されます。既存の 200 件すべてがピン留めされている場合は、その中で最古のクリップが削除されます。
- テキストを選んで **翻訳** を押すと、日本語は英語へ、それ以外のテキストは英語として日本語へ翻訳します。画像を選んで **文字読み取り** を押すと OCR を実行します。結果はテキストクリップとして履歴に追加され、プレビューに表示されます。
- **ペイント**では色と線の太さを選んで描けます。画像クリップの **ペイントで開く** から画像に描き足せます。消去と全消しは描き足した線に適用されます。**画像クリップに追加** で保存します。
- **メモ**ではタスクを追加・チェック・削除できます。変更は自動保存され、各行の **コピー** でテキストをクリップボードへ送れます。
- **電卓**は四則演算、括弧、小数、百分率に対応します。`50%` は `0.5` として計算します。**式と答えをクリップに追加** で結果を履歴へ保存できます。

履歴、タグ、ピン留め、メモは `%LOCALAPPDATA%\ClipIt\clips.json` に自動保存され、画像は同じフォルダの `images` に PNG 形式で保存されます。`LOCALAPPDATA` が未設定の場合はカレントディレクトリの `data` が使われます。

## OCR を有効にする

Windows で次のコマンドを実行し、ClipIt を再起動してください。

```bat
python -m pip install -r requirements-ocr.txt
```

Windows の **設定 → 時刻と言語 → 言語と地域** で、日本語や英語の OCR 対応言語パックを追加してください。ClipIt は利用できる日本語と英語の認識エンジンを使用します。

## EXE の作成

Windows で `build_exe.bat` を実行すると、PyInstaller が `dist\ClipIt.exe` を生成します。OCR 対応の EXE を作る場合は、先に同じ Python 環境へ `requirements-ocr.txt` をインストールしてください。実行先では Windows の OCR 言語パックも必要です。

## 既知の制約

- Ctrl+Shift+V を別のアプリが使用している場合は、トレイからパネルを表示できます。
- Windows の権限制限により、管理者権限で実行中のアプリなどへ自動貼り付けできないことがあります。その場合は対象アプリで Ctrl+V を押してください。
- 翻訳にはインターネット接続が必要で、選択したテキストは Google 翻訳へ送信されます。非公式エンドポイントのため、サービス側の変更や長いテキストによって失敗する場合があります。
- OCR の認識精度は画像や言語パックによって変わります。Windows OCR の寸法上限を超える画像は、縮小してから読み取ってください。
