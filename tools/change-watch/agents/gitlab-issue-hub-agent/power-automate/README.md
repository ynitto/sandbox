# Power Automate からハブへ依頼を書く

ここはメールをハブの issue の依頼コメントにするためのもので、メールを Teams のカードにする `tools/gitlab-mail-teams/power-automate/` とは目的が違うので混ぜない。

## フローの組み方

1. 「新しいメールが届いたとき (V3)」を選び、件名や差出人で絞る。
2. 「Html からテキスト」でメールの本文をテキストにする。
3. 件名から変数「種別」を決める。下の表の上から順に当てる。
4. 「条件」で種別が空かを調べる。
   - 種別があるときは、件名・項目・本文から変数「コメント」を組み立てる。
   - 種別が空のときは、`【未分類】<件名>` と本文を「コメント」に入れる。ハブは反応しないので、人が読んで新しい依頼を書く。
5. 「作成」で改行をそろえ、コメント全体の行頭の `/` を `\/` にする。その結果を別の「作成」で `{"body": …}` にする。
6. HTTP でハブの issue に POST する。送信先と認証は [エージェントの README の「Power Automate とつなぐ」](../README.md#power-automate-とつなぐ) のとおり。
   応答の `id` は、返信の `元の依頼: note_<ID>` と突き合わせられる。

式は [貼り付ける式の一覧](request-comment.expressions.md) を使う。Power Automate の実機では未確認なので、関数名と動的コンテンツの名前は自分のフローで確かめる。

## 件名と種別

| 件名に含む語 | 種別 |
|---|---|
| 集計・レポート・報告 | `report` |
| アカウント・権限 | `account` |
| 問い合わせ・問合せ・質問 | `inquiry` |
| どれも無い | 空 |

語は例。自分の職場の件名に合わせて直す。

## メールのどこを写すか

| メール | コメントに書く場所 |
|---|---|
| 件名 | 1 行目の種別タグのあと |
| 差出人 | `差出人: …` |
| 受信日時 | `受信日時: 2026-11-19 09:30`（日本時間） |
| 受信日時から作る番号 | `受付番号: M20261119093000`（返信にも写る） |
| 本文（`report`・`account`） | 項目行の続き。差出人に本文の先頭へ必須の項目を書いてもらい、自由な文の前に空行を入れてもらう |
| 本文（`inquiry`） | 空行を 1 つ入れ、全文を自由な文にする |

必須の項目が足りなければ、振り分け例が差し戻しのコメントを書く。GitLab が issue を見ている人に通知メールで知らせる。

## 動かす前に確かめる

種別が付いたコメントを 1 つファイルに保存し、次のコマンドで `"ok": true` になることを見てからフローを有効にする。

```bash
change-watch --plugin gitlab_hub check-request --text-file=request.txt
```
