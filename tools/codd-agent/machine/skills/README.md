# 同梱スキル

このフォルダは CLI やネットワークが無い環境で配置するためのスナップショット。

- `caveman/`: [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman) のローカル導入済みスキル。
- `graphify/`: [graphifyy](https://pypi.org/project/graphifyy/) のローカル導入済みスキル（マーカー `0.9.43`）。参照ファイルも同梱。

スキルの本文は変更していない。更新するときは `SKILL.md` と参照ファイルを一緒に入れ替える。
配置済みの同名スキルは維持する。codd のマシン内のコピーは `init.py` の再配置で更新する。
