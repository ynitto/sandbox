# 読み書きの手順

codd のどの段でも、ファイルを読み書きするときはこの手順に従う。会話に入れるのは、判断に要る行だけにする。

- ファイルを丸ごと開かない。`explore` / `impact` が示した行と、その前後だけを読む。文書は
  `context-mode search 語 --project .` で関係する節を引く
- 数える・集める・一覧にすることは、短いスクリプトに書いて実行し、結果だけを出させる（読み込んで自分で数えない）
- テストや検査の長い出力は、示された `.codd/logs/` のファイルから検索で読む。全文を読むためにテストをやり直さない
- 書くときは、計画に挙げたファイルの変える箇所だけを書き換える（ファイルを丸ごと書き直さない）
