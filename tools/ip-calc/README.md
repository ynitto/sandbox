# ip-calc

IPv4 / IPv6 のサブネット情報、IP アドレスの包含、ネットワーク同士の重なりを調べる CLI です。Python 3.7 以上の標準ライブラリだけで動きます。以下の例はリポジトリのルートから実行します。

CIDR は `IPアドレス/プレフィックス長` で指定します。ホストビットが立っていても受け付け、例えば `192.168.1.10/24` は `192.168.1.0/24` として扱います。

## `info <CIDR> [--json]`

ネットワークアドレス、プレフィックス長、アドレス総数、使用可能ホスト範囲と個数を表示します。IPv4 ではブロードキャストアドレス、ネットマスク、ワイルドカードマスクも表示します。プライベートやループバックなどの判定は、実行環境の Python の `ipaddress` によるネットワーク単位の判定です。

```sh
python3 tools/ip-calc/ip_calc.py info 192.168.1.10/24
python3 tools/ip-calc/ip_calc.py info 2001:db8::/64 --json
```

- IPv4 の `/0` から `/30` では、ネットワークアドレスとブロードキャストアドレスをホスト範囲から除きます。最初の例では `192.168.1.1` から `192.168.1.254` の 254 個です。
- IPv4 の `/31` は RFC 3021 のポイントツーポイントリンクでの扱いに従い、両端の 2 個を使用可能とします。`/32` はその単一アドレスを使用可能とします。`/31`・`/32` のブロードキャスト欄には、`ipaddress` が返す範囲末尾のアドレスを表示します。
- IPv6 ではプレフィックス内の全アドレスをホスト範囲として表示します。ブロードキャストは「なし」と表示します。
- `--json` は英語の snake_case キーを持つ JSON を標準出力に書き出します。IPv6 の `broadcast_address`、`netmask`、`wildcard_mask` は `null` です。

## `contains <CIDR> <IP>`

CIDR に指定の IP が含まれるかを調べます。使用可能ホスト範囲に加え、CIDR 内の両端のアドレスも判定対象です。次の例では「含まれる」と表示します。

```sh
python3 tools/ip-calc/ip_calc.py contains 192.168.1.0/24 192.168.1.42
```

## `overlap <CIDR1> <CIDR2>`

重なる場合は交わりの CIDR と両端のアドレスを表示します。次の例での交わりは `192.168.1.128/25` です。

```sh
python3 tools/ip-calc/ip_calc.py overlap 192.168.1.0/24 192.168.1.128/25
```

## 終了コード

| コード | 意味 |
| --- | --- |
| 0 | `info` の表示成功、IP が含まれる、またはネットワークが重なる |
| 1 | IP が含まれない、またはネットワークが重ならない |
| 2 | 不正な入力、IPv4 と IPv6 の混在などの使い方エラー。理由を標準エラーに表示 |
