# CHANGELOG フラグメントの集約

`CHANGELOG.md` への直接追記によるコンフリクトを避けるため、`changelog/unreleased/` に置いたフラグメントをまとめて取り込みます。

## 使い方

リポジトリのルートで実行します。

```sh
python3 tools/changelog-collect/changelog_collect.py
```

- `--dry-run` を付けると、ファイルを変更せずに取り込み予定を確認できます。
- `--changelog` で取り込み先のファイル、`--fragments-dir` でフラグメントのディレクトリを指定できます。

## 動作

`README.md` を除く Markdown フラグメントをファイル名順に `## [Unreleased]` の直後へ挿入し、取り込んだフラグメントを削除します。同じ `###` 見出しが取り込み先にすでにあるフラグメントは、警告を表示してスキップします。

## 終了コード

- `0` は成功、または取り込み対象なしです。
- `1` は `## [Unreleased]` が見つからない場合や、ファイルの読み書きに失敗した場合などのエラーです。
