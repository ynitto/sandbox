## 目的

指定フォルダの直近のコード変更に README・設計書・手順書を追随させる下書きを作る。doc-drift-detector や codd-gate の決定的検査の結果があれば入力に使い、指摘をコードの差分と照合する。

## 入力

- `target_dir`（対象フォルダ）＝ `{{target_dir}}`
- `revision_range`（比較する Git リビジョン範囲）＝ `{{revision_range|HEAD~1..HEAD}}`
- `check_results`（doc-drift-detector や codd-gate の既存結果のパス。複数可）＝ `{{check_results|指定なし}}`
- `output`（作業フォルダからの成果物パス）＝ `{{output|docs-followup-draft.md}}`

## 期待成果物

`output` に Markdown で、変更の根拠（コミットやファイル）、対象文書と節、現状との違い、差し替え文案を記す。参照できなかった入力や判断を保留した点を記録し、元の文書は編集しない。

## 検収観点

- 指定パスに成果物があり、対象文書と節を特定できるか。
- 差し替え文案がコードの挙動と一致し、根拠を追跡できるか。検査結果を使った場合は対応する指摘をたどれるか。
- 裏付けのない断定がなく、元の文書やコードに変更が入っていないか。

確認や質問はしない。既存テストを壊さない。依頼にない大規模な変更はしない。できなかったことは理由とともに報告する。
