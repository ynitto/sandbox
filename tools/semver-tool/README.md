# semver-tool

SemVer 2.0.0 のバージョン文字列を検証・比較・更新し、指定したレンジを満たすか判定する CLI です。Python 3.7 以降の標準ライブラリだけで動作します。

## 使い方

リポジトリのルートから実行します。

```sh
python3 tools/semver-tool/semver_tool.py check v1.2.3+build.7
python3 tools/semver-tool/semver_tool.py compare 1.0.0-rc.1 1.0.0
python3 tools/semver-tool/semver_tool.py bump 1.2.3 --part pre --pre-id beta
python3 tools/semver-tool/semver_tool.py satisfies 1.4.0 '>=1.2.0 <2.0.0'
```

## サブコマンドとオプション

| コマンド | 動作 |
| --- | --- |
| `check <version>` | 有効なら `valid` を表示する。 |
| `compare <a> <b>` | 優先順位の比較結果を `-1`、`0`、`1` で表示する。 |
| `bump <version> --part major\|minor\|patch\|pre [--pre-id <id>]` | 指定した部分を更新し、結果を表示する。 |
| `satisfies <version> <range>` | 判定結果を `true` または `false` で表示する。 |
| `-h`、`--help` | ヘルプを表示する。各サブコマンドでも使用できる。 |

## バージョンと更新の規則

先頭に小文字の `v` を付けられます。比較とレンジ判定ではビルドメタデータを無視します。更新結果には先頭の `v` やビルドメタデータを含めません。

- `major`、`minor`、`patch` は指定した数値を 1 増やし、それより下位の数値を 0 に戻します。プレリリースは取り除きます。
- `pre` は既存のプレリリースの末尾が数値なら 1 増やし、それ以外なら末尾に `.1` を追加します。プレリリースがない場合は `--pre-id` の識別子と `.1` を追加します。識別子の既定値は `rc` です。

## 対応するレンジ

| 記法 | 判定方法 |
| --- | --- |
| `1.2.3`、`v1.2.3` | 優先順位が等しければ一致。 |
| `^1.2.3`、`^0.2.3`、`^0.0.3` | 指定バージョン以上で、最初の非ゼロの部分を上げたバージョン未満。全て 0 の場合はパッチを上げる。 |
| `^1`、`^1.2`、`^0`、`^0.2`、`^0.0` | 省略部分を 0 で補ったバージョン以上。上限は順に `<2.0.0`、`<2.0.0`、`<1.0.0`、`<0.3.0`、`<0.1.0`。 |
| `~1.2.3`、`~1.2`、`~1` | 省略部分を 0 にしたバージョン以上。マイナー指定時は次のマイナー未満、メジャーのみ指定時は次のメジャー未満。 |
| `>=1.2.0 <2.0.0` | 空白区切りの比較条件をすべて満たせば一致。演算子は `>=`、`<=`、`>`、`<`、`=`。 |
| `1.2.x`、`1.x` | それぞれ `>=1.2.0 <1.3.0`、`>=1.0.0 <2.0.0` と同じ。 |
| `*`、`x` | 有効なバージョンすべてに一致。 |

プレリリースを含むレンジ判定は、優先順位の比較としてそのまま評価します。たとえば `2.0.0-rc.1` は `<2.0.0` を満たします。同様に `0.3.0-rc.1` は `^0.2.3` の上限である `0.3.0` より優先順位が低いため、`^0.2.3` に一致します。

## 既知の制限

複数の条件を組み合わせられるのは比較演算子を使う AND 条件だけです。OR（`||`）、ハイフンレンジ、演算子とバージョンの間の空白には対応していません。

## 終了コード

| コード | 意味 |
| --- | --- |
| 0 | 正常終了。`check` の検証成功と `satisfies` の一致を含む。 |
| 1 | `check` のバージョンが無効、または `satisfies` のレンジが不一致。 |
| 2 | 引数または入力エラー。理由を標準エラーに表示する。 |
