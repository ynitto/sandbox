### teams-sharepoint-bridge-agent: ハブ 1 つと作業フォルダ複数の形を標準として書く

- README の「用意と動かし方」を、ハブのフォルダを 1 つ用意して自動実行をそこで 1 つだけ動かし、作業するフォルダ（宛先）をいくつでも登録する形に書き直す。宛先ごとの登録（`target add`）と、ハブの自動実行のプロンプトの出し方も手順に入れる。
- `targets.json.example` を、`hub` と 3 つの宛先の例にする。
- copilot-app-jobs の README に、振り先はいくつでも登録でき、自動実行は受け箱のあるフォルダに 1 つで足りることを書く。
