# agent-app セッション公開と共有検索

ユーザー承認: 2026-09-15。会話メニューから開始・停止でき、ターン終了後も公開可能。公開中の後続ターンを反映する。既存の合言葉による共有範囲、共有画面、端末ミラー、ひとことを再利用する。閲覧者はCLIを操作しない。公開情報は依頼キューと独立して永続化する。

検索はローカルを既定とし、「共有も検索」を押した場合に限り共有先へ問い合わせる。条件を変更するとローカルへ戻す。公開側で条件を適用し、結果は最大50件のページとして統合する。本文は選択時のみ転送する。接続は最大3並列、タイムアウト・キャンセル・世代番号で古い結果を除外する。結果、プレビュー、フォーク、タスク等への転用は既存SessionBrowserを再利用する。公開停止・変更は読み直し時に検証する。

共有画面では公開セッションを既存一覧へ追加し、選択中のみ定期更新する。本文・コメントは保存済み会話から取得でき、終了後も閲覧・コメント可能。

検証: 公開/停止/再起動、非公開データの隔離、終了後と後続ターン、コメント、端末表示、条件検索、ページ送り、キャンセル、接続失敗、フォーク、既存共有回帰。
