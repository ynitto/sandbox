# agent-app タスクポータルとタブ式ワークベンチ実装計画

## 1. 現状の回帰テストを追加する

- 埋め込みナビゲーションで定義済みタスクが概要を開くテストを追加する。
- 手順とAI相談が別画面遷移になっている箇所を、期待するタブ遷移としてテスト化する。
- 単体版の戻る操作を保護するテストを追加する。

## 2. 埋め込み用タスク詳細シェルを作る

- 選択中タスクとタブ状態を一箇所で管理する。
- 概要、手順、AI相談、履歴のタブを描画する。
- タスク種別に応じて利用可能なタブだけを表示する。

## 3. 既存機能をタブ内容へ接続する

- 概要と履歴は既存の実行詳細を再利用する。
- 手順は既存エディターを、agent-app の詳細タブとして表示する。
- AI相談は既存 teaching feature を、選択タスクを保ったまま表示する。
- 未保存変更ガードと非同期実行状態を維持する。

## 4. 埋め込みナビゲーションを整理する

- 埋め込み時の maker ヘッダー、ホームタブ、戻るボタンを非表示にする。
- agent-app からのタスク選択時だけ初期タブを概要へ戻す。
- 新規・未定義タスクはAI相談を開く。
- maker単体版のナビゲーションは変更しない。

## 5. 検証する

- statemachine-maker のユニット／Electronテストを実行する。
- agent-app のユニット／Electronテストを実行する。
- 画面サイズとキーボードフォーカス、エラー・空状態を確認する。
- diffを簡素化レビューし、不要な分岐や重複を除去する。
